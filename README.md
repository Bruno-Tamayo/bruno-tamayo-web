# Bruno Tamayo — sitio oficial

Sitio estático bilingüe (español/inglés), adaptable a móviles y preparado para GitHub Pages.

## Archivos
- index.html: página de inicio, biografía, catálogo y contacto.
- assets/bruno-portrait.svg: retrato editorial optimizado.
- assets/favicon.svg: icono de marca.

## Activar GitHub Pages
En el repositorio, abre Settings → Pages. En Build and deployment, selecciona Deploy from a branch, rama main, carpeta /(root) y pulsa Save. GitHub mostrará la URL pública cuando termine el despliegue.

## Dominio propio
El sitio está preparado para brunotamayo.com después de registrar el dominio y configurar los DNS en el proveedor correspondiente. El dominio aún no está registrado ni conectado.

## Antes de anunciar la web
Confirma las sinopsis y el estado comercial de cada libro, agrega enlaces de compra reales, correo de prensa y perfiles sociales oficiales. Los títulos marcados como preparación o desarrollo no deben anunciarse como disponibles.

Este sitio no incluye formularios conectados ni servicios de pago.
